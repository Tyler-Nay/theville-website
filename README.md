# The Ville Athletics Website Starter

## How to use

1. Unzip this folder.
2. Open the folder in VS Code.
3. Open a terminal inside the folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open:

```txt
http://localhost:3000
```

## What to change later

- Replace TeamSnap placeholder link in `app/register/page.tsx`
- Replace Square placeholder link in `app/tournaments/page.tsx`
- Update contact info in `components/Footer.tsx`
- Update copy and pricing in `app/programs/page.tsx`

## Domain later

When ready, deploy to Vercel and connect:

- `thevillelv.com` as the main domain
- `thevilleclub.com` as a redirect
